# eden

## Purpose

Switch 1 emulator derived from Yuzu and Sudachi. One-package Home Manager app generated by the shared
`domains/lib/mkSimpleApp.nix` factory (Law 2: name = folder).

## Boundaries

- ✅ Manages: `hwc.home.apps.eden.enable` → `pkgs.eden` on `home.packages`.
- ❌ Does not manage: eden configuration, keybinds, or MIME/default-application associations.

## Structure

- `index.nix` — mkSimpleApp call: name, description, package selector.
